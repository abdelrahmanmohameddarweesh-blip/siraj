# Sirag — same-day full planting test

After confirming a habit once, the garden immediately unlocks all five interactive actions: seed, soil, water, sprout care, and bloom. Each completed scene action advances to the next without requiring another daily check-in. The single daily completion is saved once; the full growth sequence persists locally. If interrupted, opening the garden resumes the pending action.

This is the rapid concept-validation loop, not a claim that five separate worship activities were completed. Missing future days does not remove growth.

Test: choose a new habit, confirm it once, finish each interaction in the world, and watch all five stages complete in one session. Check that only one daily check-in was recorded.
